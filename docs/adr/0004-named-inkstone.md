# ADR-0004：命名 Inkstone 纸研（id inkstone），而非 kami

- 状态：已接受（2026-11-19，三轮访谈收敛）
- 对应蓝图：PLAN.md §2 决策 9；出处与定位见 §0、§1、§13

## 背景

项目脱胎于 tw93/kami 设计系统，最直白的名字就是 kami。但社区已有 Kami Reader 主题（KKenny0/obsidian-kami，仓库 obsidian-kami）：若插件也叫 kami 或用近似 id，在社区插件目录、搜索结果与用户认知中都会混淆归属，容易被误认为同一作者的配套物或官方衍生，也给审核与后续沟通埋下麻烦。插件需要的是独立、可辨、且能坦承血缘的身份。

## 决策

命名 Inkstone，中文「纸研」，插件 id 为 `inkstone`（PLAN.md §2 决策 9）。砚：纸墨之间承墨研磨之物，与「为笔记承载纸感排版」的角色对应。在文档与 README 中明确：非官方衍生自 tw93/kami，与 Kami Reader 主题互补。

取舍：放弃与 Kami 本尊共享名称带来的辨识便利，付出一个需要解释的意译名——名字与设计系统的血缘不直观，须靠致谢与文档反复交代；换取社区目录中的唯一身份、搜索可辨，以及「非官方衍生」这一诚实定位的表述空间。

## 后果

- 正面：id 与名称在社区目录中独立可辨，无混淆、无冒认官方之嫌；「纸研」的中文语义与项目气质自洽；为双语 README 的定位陈述留出空间。
- 负面：名称与 kami 的关联需靠文档持续解释；提交审核时需确认 `inkstone` id 在社区目录未被占用，若被占用需另议名字并回改 manifest。
